TrimsKit

PvP kits and a buy-and-sell economy for your Minecraft game or server. Easy to use, and built by one developer.

Download 1.4.55 See the commands
Minecraft 26.2 Fabric Client & server

The kits aim to replicate the DonutSMP style of PvP, while the economy lets players buy rare items for cheap. It suits any server that wants economy and PvP together.

Commands

Use /register and /login first. They are required for the economy and other commands.


/register

Create your account. Needed to use the economy and other commands.

/login

Log in to your account.

/sell

Sell items for money.

/buy

Buy items with money.

/kits

Open the PvP kits to fight other players.

/adin kits

Admin kits. Written exactly as it appears on the CurseForge page.

/rtp

Teleport somewhere random.

/sfmode

Operator command. See Operator and /sfmode for setup.

Installation

  1. Install the Fabric loader for Minecraft 26.2.
  2. Download trimskits-1.4.55.jar from the CurseForge files page.
  3. Put the .jar in the mods folder of your Minecraft folder (client) or your server folder.
  4. Launch the game or server.

TrimsKit runs on both client and server.

Operator and /sfmode

To become a server operator or use /sfmode, configure the OPS.json file:

  1. Launch the game once, then quit.
  2. Open your Minecraft folder.
  3. Go to the configs folder and open OPS.json.
  4. Edit it and set anything you want.
minecraft/configs/OPS.json

If you can't find OPS.json, launch the game once and check again. The file is created on first launch.
